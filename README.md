# 📊 Student Performance Analysis

## 🚀 Project Overview

This project analyzes student performance using Python, Pandas, and Matplotlib.

The dataset includes:
- Student Names
- Marks
- Attendance
- Study Hours

The objective is to explore patterns, identify trends, and visualize data using different chart types.

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib

---

## 📈 Visualizations Created

- Bar Chart
- Histogram
- Scatter Plot
- Pie Chart
- Box Plot

---

## 🔍 Key Insights

- Identified top-performing students.
- Analyzed the distribution of marks.
- Explored the relationship between study hours and marks.
- Examined attendance trends.
- Visualized data to gain meaningful insights.
